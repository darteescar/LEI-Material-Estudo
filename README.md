# Material de Estudo LEI

Website colaborativo de material de apoio para a Licenciatura em Engenharia Informática (LEI)

**Acede ao site:** https://darteescar.github.io/LEI-Material-Estudo/

---

## Conteúdo
O material encontra-se organizado por unidades curriculares.
Cada cadeira tem a sua própria página com resumos, fichas, resoluções e outros recursos de apoio ao estudo.

> ⚠️ Este material não substitui aulas nem conteúdos oficiais disponibilizados pelos docentes.

---

## Contribuições
Este repositório é colaborativo.

Se quiseres contribuir:
- abre uma **issue** com sugestões ou correções
- ou envia um **pull request** com novo material

Consulta a página principal do site para créditos completos e avisos importantes.
